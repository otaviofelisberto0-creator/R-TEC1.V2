Critérios aplicados

  • Grupo OS: coluna UN_RESP.
  • MIGRAÇÃO: UN_RESP = INSTALACAO, GRUPO_OS = SERVICOS, TIPO_OS = MUDANCA DE PACOTE e LISTA_ID_OS = 24.
  • ADESÃO: UN_RESP = INSTALACAO, GRUPO_OS = INSTALACAO e LISTA_ID_OS = 1, 43, 51 ou 516.
  • O JSON é agregado por data, serviço, Grupo, Cluster, SubCluster, Cidade, UN e EPO para reduzir o tamanho.
